Porto documentation

How to install, run and troubleshoot Porto, and how to work on it. These pages are published from the Porto repository at release v1.11.6.

Use Porto

New to Porto? Start with the quickstart, then installation for platform details.

Get started

  • Overview and quickstartWhat Porto does, platform support, the four-step quickstart and important limitations.
  • InstallationInstall a release, verify downloads, build from source and handle desktop updates.
  • Daily useKeep Porto available at login or boot, navigate the dashboard and find resources.
  • DiagnosticsHealth checks, redacted support bundles and confirmed repairs.
  • Porto agent skillLet coding agents install Porto and drive projects, containers, clusters and VMs.

  • Cluster upgradesDistribution-specific upgrades, volume restoration and recovery.

Data and images

  • Runtime data managementInspection, protected cleanup, local backups, migration and native files.
  • Data compatibilityData and backup APIs, archive format, persisted schemas and upgrade recovery.
  • Image analysisDive layers, Syft SBOMs and Grype vulnerability matching.

Environments and integrations

  • Remote environmentsAuthenticated enrollment, Edge fleets, scoped actions and revocation.
  • ExtensionsVerified installation, grants, isolated actions and views, and authoring.

  • KillSwitchRequirements, commands, port ownership and troubleshooting.
